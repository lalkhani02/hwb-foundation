# Hope Without Borders Foundation

Static, multipage website at https://hwb-foundation.org, published with GitHub Pages from the main branch.

## Current project

HWB supports the continued work of a partner-operated cultural center in Turkey that has served Syrian refugees for over a decade. The project page is cultural-center.html. The previous project URL redirects to this current page.

## Donations

The Donate page embeds the CharityStack fundraiser Community Cultural Center — Continuing the Mission, with fund designation Turkey — Cultural Center Continuing Work. The prior fundraiser is deactivated and its historical donation record is preserved. Website publication does not establish payment-provider approval or payout availability.

## Editing

Edit the root HTML files for page content and assets/styles.css for design. Keep navigation and footer consistent across pages. Preserve CNAME for the custom domain. No build step is required. Do not place credentials or bank details in this public repository.
